# Hagar & Ahmed — Wedding Invitation

Static mobile-first wedding invitation, ready for Vercel. No build process needed.

## Deploy
1. Unzip this project.
2. Upload the folder to a GitHub repository.
3. On Vercel, choose **Add New > Project**, import the repository.
4. Framework preset: **Other**. Build command: leave empty. Output directory: leave empty (root).
5. Click **Deploy**.

Alternatively, install the Vercel CLI and run `vercel --prod` in the project folder.

## Features
- Tap-to-open envelope and reveal animation
- Six supplied reference images, displayed in sequence
- Supplied MP3 starts on user interaction, with pause/play button
- Quran verse in Arabic, rest of invitation in English
- Wedding countdown, event details and Google Maps search link
- Responsive layout and reduced-motion support

## Notes
The original images include baked-in names and details. Replace the image assets if you want to change those labels. The Google Maps button searches for the Citadel of Saladin rather than a precise venue entrance; update its link when you have an exact pin.
